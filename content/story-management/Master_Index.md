## How to Expand
1. For a new character: copy `Template_Character` folder and rename.  
2. Fill in `Character_Template.md`, `Token_Template.md`, and `Story_Template.md`.  
3. Update **Master_Timeline.md** with their introduction.  
4. Update this **Master_Index.md** to keep the overview consistent.

---

## Notes
- Keep file naming consistent (e.g., `Chapter_1.md`, `Tokenomics.md`).  
- Shared folders should only contain documents that apply across multiple characters.  
- Always update the index when adding new characters, tokens, or lore docs.
