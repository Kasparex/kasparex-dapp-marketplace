# Project Roles – Kasparex Characters

This document defines responsibilities for different areas of the Kasparex ecosystem.  
Use it to assign tasks as the team grows.

---

## Core Roles

### Founder / Visionary (You)
- Define overall direction of Krex’s Chronicles.
- Approve new characters, tokens, and lore expansions.
- Manage community vision and ecosystem growth.

### Developers
- Implement smart contracts (tokens, dApps, migration tools).
- Maintain Kasparex.com integrations (widgets, plugins, wallet connect).
- Support tokenomics automation (fees, treasury, burns).

### Artists / Designers
- Concept art and final renders for characters.
- NFT design, trait sheets, and metadata.
- Posters, promo graphics, memes, and visual identity.

### Writers / Lore Builders
- Write character backstories and abilities.
- Expand lore (Kaspaland, timelines, Null Gang, etc.).
- Draft community posts, Medium articles, and story chapters.

### Community Managers
- Handle Telegram, X, and Discord presence.
- Run contests, giveaways, and polls.
- Collect community feedback and report to team.

### Musicians / Media Creators
- Create soundtracks and songs (Kasparex Records).
- Design video intros, animations, and lore trailers.
- Provide voice-overs, narrations, or audio cues.

### Advisors / Partners
- Guide strategy for partnerships and liquidity.
- Connect Kasparex with exchanges, dApps, and token projects.
- Offer insights on scaling ecosystem growth.

---

## Notes
- Roles can overlap (one person may cover multiple areas).  
- Each new character or token project should have **at least one lead** assigned.  
- Update this file whenever a new contributor joins or responsibilities shift.
