# Archived documentation

Files here are **historical** session notes, one-off deployment fixes, or superseded guides. They are kept for reference but are not part of the primary maintainer path.

- **`root-session/`**  -  Ephemeral markdown that used to live at the repository root (status snapshots, “COMPLETE” / “FIX” runbooks).
- **`docs-moved/`**  -  Older docs moved out of `docs/` (e.g. TypeScript scratch log, Cloudflare Pages setup for experiments).

Active setup guides remain at the repo root (`README.md`, `SETUP_ENV_GUIDE.md`, `PRE_DEPLOYMENT_CHECKLIST.md`, etc.) and under `docs/`.
