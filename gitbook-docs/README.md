# Kasparex dApp Marketplace Documentation

Welcome to the Kasparex dApp Marketplace documentation. This documentation is automatically generated from the marketplace configuration.

## Available dApps

- [Subscription Checker](./dapps/subscription-checker.md) - Let users pay monthly in KAS to access content.
- [Token Payment Splitter](./dapps/token-payment-splitter.md) - Automatically distribute token payments across multiple recipients based on predefined percentages.
- [Multi-Choice Voting Panel](./dapps/multi-choice-voting-panel.md) - Enable decentralized governance through token-weighted voting on Kaspa network.
- [Idea Submission Box](./dapps/idea-submission-box.md) - A Web3 idea submission system where community members can share and track ideas linked to their wallet addresses.
- [Custom dApp Page Builder](./dapps/custom-dapp-page-builder.md) - Build custom dApp homepages effortlessly by reading token metadata and rendering content with customizable templates.
- [Token Profile Page](./dapps/token-profile-page.md) - Create and verify token project profiles on Kasparex with on-chain ownership verification.
- [Hold-to-View Threads](./dapps/hold-to-view-threads.md) - Hold-to-view content system that reveals replies and deep content only to verified token holders.
- [Voting Tournament Tool](./dapps/voting-tournament-tool.md) - Create and manage bracket-style voting tournaments where community members vote on pairings using token-based contracts.
- [Token Milestone Logger](./dapps/token-milestone-logger.md) - Record and track major token milestones on-chain, including DEX listings, holder milestones, and significant events.
- [Anonymous Feedback Box](./dapps/anonymous-feedback-box.md) - Enable anonymous feedback collection from community members with a small KAS fee per message to prevent spam.
- [Simple Payment](./dapps/simple-payment.md) - Send KAS payments with automatic fee collection to support the Kasparex ecosystem.
- [DAO Voting](./dapps/dao-voting.md) - Submit and vote on future dApp ideas for marketplace integration
- [Quiz-to-Earn](./dapps/quiz-to-earn.md) - Answer crypto and ecosystem questions to earn GRID or token rewards
